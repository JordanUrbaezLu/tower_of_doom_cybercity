# Rampage Inducer

`native_review.blend` and `native_review.png` review the actual installed native
mesh and textures, with OFF on the left and ON on the right. Blender's lighting
is illustrative and does not include the game's active sparks/pulsing lights.
The game appearance is awaiting the user's test.

`install_manifest.json` pins the generated GDT, native binary and textures.
Repair rationale, source assets and regeneration tools are documented in
`../../docs/163_rampage_inducer_presentation.md`.
